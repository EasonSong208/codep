# 2025年“星航新干”培训班核心背诵指南

## 一、 必考核心数据（填空、判断、单选重灾区）

### 1. 年龄与时效限制

* **入团年龄**：14周岁以上，28周岁以下 。
* **超龄离团**：年满28周岁，没有担任团内职务，应该办理离团手续 。团员加入共产党后保留团籍，年满28周岁且无团内职务则不再保留 。
* **青年突击队**：人数一般在 **5人** 以上 ；队长年龄原则在 **40周岁** 以下 。
* **青年文明号**：集体人数一般为 **30至50人**，最少不低于 **6人**，最多不超过 **200人** ；**35周岁以下** 青年人数占 **50%以上** ；号长不超过 **40周岁** 。

### 2. 会议与培训频率

* **支部大会**：一般 **每季度** 召开一次 。必须有 **半数以上** 有表决权的团员到会，赞成票超过到会半数即为通过 。
* **支部委员会会议**：一般 **每月** 召开一次 。
* **团课**：基层团组织每个季度应安排上一次团课 。入团积极分子被确定为发展对象前集中团课学习不少于 **8学时** 。
* **团员培训**：团员每年参加集中学习培训一般不少于 **4次** 。

### 3. 比例与基数红线

* **推优入党**：“推优”比例一般不超过团支部团员人数的 **20%** ；推荐对象应有 **1年以上** 团龄，年满 **18周岁** ；推荐有效期为 **2年** 。
* **团员评议**：评议等次分为 **优秀、合格、基本合格、不合格** ；优秀等次数量控制在参加评议人数的 **30％以内** 。
* **志愿服务时长**：团员每年参加志愿服务时间不少于 **20小时** 。

### 4. 团费收缴标准

* **学生交纳标准**：学生团员每月交纳团费 **0.2元** 。
* **特殊交纳**：自愿一次多交纳 **1000元以上** 的团费，全部上缴团中央 。
* **自行脱团界定**：连续 **6个月** 不交纳团费、不过团的组织生活、不做团组织分配的工作，按自行脱团处理 。

## 二、 关键制度与名词解释（简答题防身）

### 1. “三会两制一课”

这是团的组织生活的基本制度 。

* **三会**：支部大会、支部委员会、团小组会 。
* **两制**：团员教育评议制度、团员年度团籍注册制度 。
* **一课**：团课 。

### 2. 团干部的“四个要求”

必须做到：**坚定理想信念、心系广大青年、提高工作能力、锤炼优良作风** 。

### 3. 高校“班团一体化”运行

* 班级团支部委员会应当与班委会一体化运行 。
* 具备条件的，由 **团支部书记兼任班长** 或由团员身份的班长担任团支部副书记 。
* 有学生党员的学生团支部，**原则上由学生党员担任团支部书记** 。

### 4. 临时团支部权限限制

* 可以成立的情形：为期6个月以上的工程、工作项目等 。
* **“四不”限制**：一般**不**发展团员、处分处置团员；**不**收缴团费；**不**选举团代会代表和换届；**不**开展“推优”入党工作

## 三、 高频核心实务流程（情景判断、论述题）

### 1. 纪律处分五大层级

对团员的纪律处分有五种（从轻到重排序）：

1. **警告**
2. **严重警告**
3. **撤销团内职务**
4. **留团察看**（时间为 **六个月或一年**，期间没有选举权、被选举权和表决权，不得作入团介绍人）
5. **开除团籍**（受到此项处分，原则上不能重新入团）

### 2. 发展新团员流程（时间轴记忆）

* **谈话**：收到入团申请书后，**一个月内** 派人同申请人谈话 。
* **培养**：培养联系人由 **1至2名** 团员或党员担任 。考察期必须达到 **三个月以上** 。期间谈心谈话不少于 **两次** 。
* **推荐**：年满14未满15周岁的入团积极分子，原则上须经过 **少先队组织推荐** 。
* **接收**：必须有 **两名** 团员或党员作入团介绍人 。由支部大会无记名投票表决，须过半数通过 。新团员必须参加入团仪式，在团旗下宣誓 。

### 3. “推优”入党工作流程

* 团组织向党组织推荐的原则上应当是 **团员中的入党积极分子** 。
* 须召开“推优”大会，**半数以上** 有表决权的团员到会方可进行 。
* 采取 **无记名投票**，赞成人数超过应到会有表决权团员的半数进入考察环节 。
* “推优”情况须进行公示，公示期一般不少于 **5个工作日** 。

### 4. 团员组织关系转接与脱团处置

* 外出学习、工作、生活 **6个月以上** 且地点相对固定的，应转出组织关系 。
* 毕业生未升学未就业的，原学校可保留组织关系 **6个月，最长不超过1年** 。
* 与团组织失去联系 **1年以上**，或出国长期定居、出国超过 **5年** 未归的，**停止团籍** 。停止团籍 **2年后** 仍无法联系的，予以 **除名** 。

## 四、 核心思想教育与团建要求（大题与填空金句）

### 1. 团的根本定位与三大任务（必背金句，极易考论述或填空）

写任何论述题，只要涉及共青团的工作方向，直接把这三句话作为总起：

* **根本任务** *：把培养社会主义建设者和接班人作为根本任务 **。***
* **政治责任** **：把巩固和扩大党执政的青年群众基础作为政治责任**
* **工作主线** **：把围绕中心、服务大局作为工作主线**
* **三大基本职责** ：认真履行引领凝聚青年、组织动员青年、联系服务青年的职责

### 2. 团的建设“六个坚持”（团章基本要求，极易考简答题）

如果考题问“共青团建设必须贯彻哪些基本要求”或“如何加强新时代共青团建设”，直接默写这六条：

1. **坚持党的领导**。
2. **坚持把帮助青年确立正确的理想、坚定的信念作为首要任务**。
3. **坚持服务青年的工作生命线**。
4. **坚持民主集中制** （注：这也是共青团根本的组织原则）。
5. **坚持改革创新** （注：基层组织是团的一切工作的基础，要确立基层第一的观念） 。
6. **坚持从严治团** （注：首先从团干部严起，坚决反对机关化、行政化、贵族化、娱乐化倾向） 。

### 3. 思想政治引领核心考点（高频专有名词）

* **主责主业** **：**共青团要聚焦**“为党育人”的**主责主业
* **四个之（宝贵经验）** ：坚持党的领导的立身之本、坚守理想信念的政治之魂、投身民族复兴的奋进之力、扎根广大青年的活力之源 。
* **政治站位（高频词汇）** ：深刻领悟**“两个确立”**的决定性意义，切实增强**“四个意识**”、坚定**“四个自信”**、做到**“两个维护”**
* **三大品牌工程（常考选择或名词解释）** ：
  * **网上主题团课品牌：***“青年大学习”*。
  * **理论宣讲轻骑兵：“青年讲师团”计划 。
  * **青年政治骨干培养：** **青年马克思主义者培养工程** ，简称“青马工程”。
